# Sercans PKW Schmiede

Website der Kfz-Werkstatt **Sercans PKW Schmiede** – Next.js 15 (App Router), React 19, Tailwind CSS 4, TypeScript (strict).

## Projektstruktur

| Ordner      | Inhalt                                                                                                                         |
| ----------- | ------------------------------------------------------------------------------------------------------------------------------ |
| `frontend/` | Komplette Website inkl. Server-Logik (Kontaktformular via Server Action + Resend). Wird auf **Vercel** deployt.               |
| `backend/`  | Reserviert für spätere, eigenständige Dienste (z. B. Railway). Für den Betrieb der Website aktuell **nicht** erforderlich.     |

Details zu Architektur, Setup, Deployment und Platzhaltern: [`frontend/README.md`](frontend/README.md).
